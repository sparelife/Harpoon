# 使用说明

可转债的奥卡姆剃刀，记住两点：

- 第一：所有的投入前提都是以胜为前提，“是故胜兵先胜而后求战”
- 第二：每年只有一两次机会符合第一个条件，“耐心等待就有巨大回报”

0. `kgoodlist` 是季度级别静态分析的列表，主要作用是排除动态数据看不到的较差质地的转债：使用 `kgoodlist.xlsx` 列表中列出的参数进行积分计算，选择得分较高的标的下注；其中的“下修意愿”涉及到公司想不想还钱的问题，一般情况都是能拖就拖，最后强赎——毕竟这么低成本的钱谁不想要

1. 先使用 `harpoon` 过滤出价格（<121）、市值（<5）和剩余年限在（2 到 5 之间）都满足要求的备选可转债

2. 使用 `missiles`（与 `bombs` 的区别主要是赔率和胜率的估计方法）计算可转债的年波动性指标，作为备选积分列表的一个参数；下注比例用于复制决策该赔率下的购买资金

3. 下注时把总投入规模平均分给每个预投标的，然后每个可转债按照凯利公式计算的比例 f 独立下注

4. 按照卡神的说法，结合自己的经验，双低摊大饼有致命缺陷——该策略只是在消耗时间而并没有赚取收益，其实更要关注波动性（异常）才能获取收益，当然前提是税前收益为正。以“保底价格”垫厚、以“异动价格”增强收益，年均异常和下注率联合过滤，可得到一个较好的列表

5. 买入时特别注意下跌后的一些边际可转债，即波动后跳出在备选列表中的转债——这些转债较大可能是因为情绪波动造成的

6. 自动卖出后不要轻易再买入，这也许是最自然的仓位控制办法：收割结果的、闲置不结果的，否则没有太好的办法解决仓位控制问题，因为按照下注比例解决，也仍然需要一个“时机”的问题，不可能每天去调整。按照以上方式源源不断地产生现金流，使得整个过程能够持续下去

## harpoon.py — 数据获取与初筛

从集思录获取全市场可转债数据，计算**马氏距离**（基于理想样本的转股溢价率/纯债溢价率协方差），按配置过滤后输出分析报告。

```
用法: python harpoon.py [日期]

  [日期]     不填            今天（默认）
             2026-06-18    指定日期

  过滤条件在 jisilu_config.json 中配置

示例:
  /opt/finance_env/venv/bin/python harpoon.py
  /opt/finance_env/venv/bin/python harpoon.py 2026-06-26
```

**输出目录结构：**
```
data/<YYYYMMDD>/
├── <YYYY_MM_DD>_in.xlsx          ← 集思录原始数据
├── <YYYY_MM_DD>_out.xlsx         ← 分析结果（analyze / kgood / selected 三个标签页）
└── <YYYY_MM_DD>_image.png        ← 散点图（马氏距离着色 + 等距椭圆）
```

**selected 标签页字段：** `代码`、`转债名称`、`剩余规模`、`含息价`、`剩余年限`

## bombs.py — 低溢价波动策略分析（策略A）

与 missiles.py 结构相同，区别在于策略逻辑和过滤参数：

- 策略A关注：**低转股溢价率 + 高波动性**
- 使用异常交易日最高价中位数估算参考估价
- **胜率计算逻辑：** `1 - exp(-年均命中次数 × 剩余年限) × (1 + 年均命中次数 × 剩余年限)`，即从现在到退市至少有两天日内涨幅超过异动阈值的概率
- **赔率计算逻辑：** `(参考估价 - 当前价) / (当前价 - 保底价)`，参考估价 = 所有异常波动交易日最高价的中位数
- 过滤条件：`年均异动 >= 3.0`，`下注比例 >= 0.1`

```
用法: python bombs.py <文件路径> <日期>

  <文件路径>    harpoon.py 输出的文件（含 selected 标签页）
  <日期>        分析截止日期

示例:
  /opt/finance_env/venv/bin/python bombs.py data/20260625/2026_06_25_out.xlsx 2026-06-25
```

**输出：**
```
data/<输入日期目录>/
├── <yyMMdd>/                     ← 中间数据（与 missiles.py 共用缓存）
└── <日期>_kelly_bombs.xlsx       ← 最终结果（kelly / opt-kelly 标签页）
```

## missiles.py — 双低策略分析（策略B）

基于 harpoon.py 输出的 `selected` 标签页，用凯利公式估算胜率/赔率/下注比例：**胜率**查 `probability.xlsx`（bayes 表）的强赎后验概率，**估值距离**按马氏距离计算并输出。

```
用法: python missiles.py <文件路径> <日期>

  <文件路径>    harpoon.py 输出的文件（含 selected 标签页）
  <日期>        分析截止日期

示例:
  /opt/finance_env/venv/bin/python missiles.py data/20260625/2026_06_25_out.xlsx 2026-06-25
```

**输出：**
```
data/<输入日期目录>/
├── <yyMMdd>/                     ← 中间数据（每只转债的日线 + 估值分析）
│   ├── sh113546_trade.xlsx
│   ├── sh113546_valanaly.xlsx
│   └── ...
└── <日期>_kelly_missiles.xlsx    ← 最终结果（kelly / opt-kelly 标签页）
```

**胜率计算逻辑：** 从 `probability.xlsx`（bayes 表）按存续年限（=6−剩余年限，向上取整到 0.1 年）查得的强赎后验概率
**赔率计算逻辑：** `(参考估价 - 当前价) / (当前价 - 保底价)` ，参考估价 = 强赎中位数大概150

### 附录：胜率计算过程（基于历史退出转债的数据分析）

第一:历史退出的可转债中的强赎比例为93%
第二:基于强赎条件下续存期数据的可知
                P(头一年半|强赎)=0.5,存续期在0-1.5年之内的占比50%,
                P(中间两年|强赎)=0.4,即存续期在1.5-3.5年内的占比40%，
                P(后两年半|强赎)=0.1,存续期在3.5-6年内的占比为10%
胜率计算p：由于1年内无法获取足够的波动数据，因此选择的转债2.5<剩余年限<4.5年共的中间两年的强赎概率
基于以上分析粗略的分析结合贝叶斯定理可知
P(强赎|中间两年) = P(中间两年|强赎)P(强赎)/P(中间两年) 
                 = P(中间两年|强赎)P(强赎)/(P(中间两年|强赎)P(强赎)+P(中间两年|非强赎)P(非强赎))
                 = 0.4*0.93/(0.4*0.93+ 0.2 * 0.07) 
                 = 0.96
赔率计算b:假设强赎价格150,买入价为120，保底价为115那么赔率大概为(150-120)/(120-115)=6
下注比例f=(p(b+1)-1)/b=0.9左右，该数据可以作为个别转债下注的参考标准
注意其中P(中间两年|非强赎)需要单独统计


另外依据相同的方法可计算：P(强赎|头一年半) = 0.98  
                          P(强赎|后两年半) = 0.65
                          P(强赎|最后一年) = 0.39
由此越往后强赎的机会越小最后一年胜率较低

第三：小于5亿发行规模的可转债，退市价格中位数为153
第四: missiles的胜率已改为从 probability.xlsx(bayes 表)按存续年限(=6−剩余年限,向上取整到0.1年)查得的强赎后验概率，事件与赔率(达到强赎价150)一致，可直接用凯利公式；

## 数据目录约定

| 路径 | 用途 |
|------|------|
| `./data/primary/` | akshare 原始数据缓存（跨脚本共用） |
| `./data/<YYYYMMDD>/` | harpoon.py 输出（全市场分析） |
| `./data/<YYYYMMDD>/<yyMMdd>/` | missiles.py / bombs.py 中间数据 |
| `./data/<YYYYMMDD>/<日期>_kelly_*.xlsx` | missiles.py / bombs.py 最终结果 |
| `./probability.xlsx` | 强赎后验概率表（sheet `bayes`：存续年限 0.6~6.0、步长 0.1 → 概率中位数），missiles.py 胜率查表来源 |
